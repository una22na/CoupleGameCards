# Взгляд героя — веб-прототип

Это первый простой прототип флирт-игры для двоих во время фильма.

## Что уже есть

- два игрока;
- три уровня сложности;
- случайная колода;
- карточки не повторяются до окончания колоды;
- карточки могут быть обычными или привязанными к событиям фильма;
- штрафные глотки как текст на карточке;
- очки;
- пропуск карточки с возвратом в конец колоды.

## Как запустить

1. Откройте папку в VS Code.
2. Самый простой вариант — установить расширение **Live Server**.
3. Откройте `index.html` через Live Server.
4. Игра откроется в браузере.

Никакие библиотеки или npm пока не нужны.

## Где менять карточки

Все карточки находятся в начале `app.js` в массиве `CARDS`.

У карточки есть:

- `id` — уникальный номер;
- `level` — 1, 2 или 3;
- `type` — например `пара`, `партнёр`, `общая`;
- `text` — само задание;
- `penalty` — штраф или `null`;
- `movie` — `true`, если задание связано с фильмом.

Следующий этап можно сделать уже красивее: PWA, таймеры, звуки, анимация вытягивания карточки, категории, отдельные наборы и полноценная статистика.
